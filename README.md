# INZONE H6 Air 调音参数提取工具集

把索尼 INZONE H6 Air（MDR-G600）在 INZONE Hub 里的官方调音预设，
提取成**任何平台都能用的滤波器参数**。

核心结论：**这套调音不在耳机里，也不在 USB 音频盒里，而是在 Windows 电脑上**
（由索尼的音频处理组件在音频引擎内完成）。所以它可以被完整读出来、搬到别的平台去。

## 快速开始

环境要求：**Windows** + 已安装 **INZONE Hub** + **Python 3.9+**（无需装任何包）。

```bash
# 1. 启动监听（保持窗口开着）
python tools/harvest_presets.py --seconds 300

# 2. 此时打开 INZONE Hub，把 EQ 预设逐个点一遍
#    每切换一次，终端会打印并归档一份快照

# 3. 结束后把快照配对成表格
python tools/export_presets.py --out-dir data
```

产物：`data/presets.md`（人看的对照表）、`data/presets.csv`、
`data/presets_apo/*.txt`（每个预设一份，可直接粘进 Equalizer APO）。

只想看结果的话，本仓库 `data/` 里已经有一份抓好的，直接用。

### 其他工具

python tools/inzone_eq.py             # 导出当前活动配置到五种平台格式

## 三条关键发现

1. **调音是纯软件的。** 耳机本体是纯模拟器件，USB 音频盒只做数模 / 模数转换。
   真正处理声音的是 Windows 端索尼的音频处理组件，参数以明文配置文件的形式
   写在用户目录里 —— 这也是本项目能读到它们的全部原因。

2. **有两套并行的均衡器。** 7 个预设用第一套（31.5 Hz–16 kHz），
   **RPG/Adventure 单独用第二套**（50 Hz–9.5 kHz，频点完全不同），且它会关掉第一套。
   只读第一套会把 RPG/Adventure 误判成"全平"。

3. **空间音效没做。** 它的资产是加密的，作者在确认这一点后停止，
   未提取密钥、未解密、未分发。想拿等效结果只能走测量路线
   （`tools/make_sweep.py` 已备好测试信号）。

参数本身做过验证：用标准 RBJ 公式独立复算滤波器系数，与程序自己记录的数值
**小数点后 8 位完全一致**，所以这些不是猜的。
